# 🎓 Sistema de Eventos - Universidade de São Gabriel (USG)

Projeto web desenvolvido para a divulgação e gestão de eventos acadêmicos, como palestras, workshops e simpósios da Universidade de São Gabriel.

🔗 **Link para acessar o site:** [Clique aqui para visualizar](https:https://github.com/GKurtPMW/eventos-usg)

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização com layout flexível (Flexbox), suporte a tabelas e responsividade via Media Queries.

---

## 📄 Estrutura das Páginas

* **Home (`index.html`):** Apresentação do portal e cards interativos dos eventos.
* **Programação (`programacao.html`):** Cronograma completo organizado em tabela com uso de `rowspan` e `colspan`.
* **Inscrição (`inscricao.html`):** Formulário funcional para cadastro dos participantes.
